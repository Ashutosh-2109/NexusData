# NexusData live India plan

1. Add a city registry and optional live providers behind a shared interface. Cache responses for 15 minutes, expose snapshots, history, SSE, health, and merge live observations with uploaded CSVs.
2. Add a client-only India map with city and state layers, status, metric controls, and a city detail panel.
3. Add transparent pressure scoring, versioned intervention rules, and an indicative correlation-based simulator.
4. Persist merged data and live history in SQLite, add container configuration, and replace starter documentation with setup and attribution.
5. Verify provider, cache, normalization, scoring, rules, scenario, UI, and smoke behavior; run backend tests, frontend build, and lint at each stage.

Existing routes and statistical calculations remain the source of truth. AI may only describe supplied evidence.
