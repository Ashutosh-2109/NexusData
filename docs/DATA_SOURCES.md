# Data sources and attribution

- [Open-Meteo Weather API](https://open-meteo.com/en/docs): model temperature and relative humidity. No API key is required for the default non-commercial endpoint. Attribution: Open-Meteo and its underlying weather model providers.
- [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api): model PM2.5, PM10, and NO₂. Attribution: Open-Meteo and CAMS. The global model has coarse spatial resolution; city values are estimates, not station observations.
- [OpenAQ v3](https://docs.openaq.org/): optional station observations with `OPENAQ_API_KEY`. Station coverage and licensing vary by source. The adapter supports latest and hourly history; the map's primary 48-hour series remains Open-Meteo model data.
- [WAQI API](https://aqicn.org/api/): optional station feed with `WAQI_TOKEN`. Its reported AQI is shown separately from the Indian estimate.
- [CPCB real-time AQI via data.gov.in](https://www.data.gov.in/catalog/real-time-air-quality-index): optional provisional adapter with `DATA_GOV_IN_KEY` and a resource ID. Schema and availability must be verified before operational use; live field readings may contain errors.
- [DataMeet India state boundaries](https://projects.datameet.org/maps/states/): source `States/Admin2.shp` and `.dbf`, simplified to `frontend/public/data/india_states.geojson` for display. **CC BY 2.5 India**. Attribution: DataMeet Community Maps Project. Boundaries are for visualization and may have positional or naming inaccuracies. Rebuild with `python scripts/build_state_geojson.py data/state_source frontend/public/data/india_states.geojson` after obtaining source files.
- [OpenStreetMap](https://www.openstreetmap.org/copyright): map tiles and base-map attribution, © OpenStreetMap contributors.
- City registry population: reference 2011 municipal counts where available; coordinates and municipal areas are approximate editorial values. They are not current official demographic data. See `backend/data/cities.json`.
- Maharashtra district boundaries: [OpenCity District Maps for States of India](https://data.opencity.in/dataset/district-maps-for-states-of-india), resource [Maharashtra Districts Map](https://data.opencity.in/dataset/2ae48270-ab28-4786-abf1-e36a00f0c761/resource/10a9e732-4e2e-4740-bb57-0533b6abf101?view_id=80f32264-689c-44c9-bba4-c9ede5bd58ce). Listing attribution: Vaidyanathan R; source identified as Survey of India; listing marks the resource public domain. The source KML contains 36 district features including Palghar. NexusData stores a compressed source copy in `data/raw/maharashtra_districts_source.kml.gz` and simplifies it for the browser map. Verify the listing license and attribution terms before redistribution.
